# 변경사항
### ver.1
보스 및 보스맵 구현(B키로 진입)<br>
1페이즈 : 
  보스가 원거리 공격을 하며, 근접공격 사거리 1.3배 이내 접근 시 노란색으로 경고, 근접공격 사거리 내 접근 시 빨간색으로 변한 후 회전으로 근접공격 수행
  5초마다 랜덤 구역으로 텔레포트 수행
<br><br>
레이저 페이즈 :
  보스가 사라지고, 일정 시간동안 레이저 패턴 진행<br><br>
2페이즈 : 
  보스가 지정위치에 고정되고, 정해진 패턴대로 탄막을 발사<br><br>

플레이어 :
  피격시 2초간 피격무적 적용, 플레이어 객체가 점멸하는것으로 확인 가능<br><br>

확인된 버그 : 
  근접공격 쿨타임 적용이 안되는 버그
  
<br><br>
