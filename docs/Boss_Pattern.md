# 보스 페이즈 설명
_(각 요소에서 *표시는 Constants.h에서 변경 가능한 상수)_
## 보스 진입
**B**키를 눌러서 보스 맵 진입
<br><br>
## 보스 등장
화면 상단에서 보스가 내려오면서 등장, 체력바가 천천히 차오르는 애니메이션 구현<br>
보스 체력 : 3000*, 플레이어 체력 : 100*
<br><br>
## 1페이즈<br>
보스 사용 패턴:
  1. 원거리 공격 : 1.2초* 마다 탄막 발사
  2. 근접 공격 : 근접공격 범위(150.0f*)의 1.3배 이내에 접근 시 보스가 노란색으로 바뀌면서 경고<br>
                근접공격 범위 안에 들어갈 시 보스가 빨간색으로 회전하면서 20*의 데미지로 공격
  3. 텔레포트 : 3초* 마다 텔레포트 시전, 도착 좌표는 랜덤이며, 시전 시간은 0.5초*, 시전동안은 무적이 아니며, 다른 패턴을 수행하지 않음
